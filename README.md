# Akbarkhan Muhammed — Personal Website

Personal portfolio website for GitHub Pages.

## Files

- `index.html` — the main website page
- `style.css` — the visual design

## GitHub Pages

For the repository that will host the site:

1. Upload `index.html` and `style.css` to the repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the branch containing these files (usually `main`) and the `/ (root)` folder.
5. Save.
6. GitHub will publish the site at:

   https://akbarkhan-data.github.io

## Editing

You can change text in `index.html`. Visual styling is in `style.css`.
